# antislop audit 001 (2026-09-13)

Scope: `index.html`, `src/App.tsx`, `src/App.css`, `src/index.css`.
Method: I read the code and ran the contrast script (`antislop-human/contrast-check.py`) on the page's color pairs. I did not run the app, so these findings come from the code, not a click-through (R-35).
The page is still the stock Vite + React starter. Nothing has been changed yet.

Priority comes from the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Lock = LOW.

## HIGH

1. **Counter button text fails contrast in light mode.** `src/App.css:5-6`. The text is `#aa3bff` on the `--accent-bg` tint (about `#f6ebff`). That is 3.82:1, and 16px text needs 4.5:1. *(R-25)*
2. **Tap targets are under 44px.** The counter button (`src/App.css:3`) is about 37px tall, and the link buttons (`src/App.css:124`) are about 35px. Their only feedback is on hover, with no `:active` state, so a tap on a phone shows nothing. *(R-03)*
3. **The layout has only two states.** Every media query uses the same breakpoint, `max-width: 1024px` (`src/App.css:67, 81, 92, 139, 159`, `src/index.css:28, 80, 90`). Anything from 400px to 1024px gets the phone stack. On a tablet, the two link buttons per row stretch to half the screen width each. *(R-03)*
4. **All type sizes are fixed px.** The root font is `18px`/`16px` (`src/index.css:18, 29`), and h1 is `56px`/`36px` (`src/index.css:77, 81`). The user's browser font-size setting is ignored, and type jumps at 1024px instead of scaling. *(R-03, antislop-human "Text That Cannot Zoom")*
5. **There is no design direction.** The repo has no `DESIGN.md` and no brand brief, so any UI built from here is a *draft without direction* at ENERGY 1 / RHYTHM 1 / MOTION 1. Findings 6, 7 and 11 can't be fixed properly until this exists. *(R-37)*

## MEDIUM

6. **The purple accent is a default, not a brand choice.** `src/index.css:7, 40` (`#aa3bff` / `#c084fc`). No reason for it is written down. *(R-01, R-29)*
7. **Monospace on a button, and a default system font, with no reason.** `src/index.css:98-100` puts `.counter` in `--mono`, and `src/index.css:14-15` uses `system-ui` for both body and headings without a stated reason. *(R-06)*
8. **Decorative frame lines.** The `.ticks` triangle markers (`src/App.css:164-184`), the full-height side borders on `#root` (`src/index.css:58`) and the empty `#spacer` band (`src/App.tsx:117`, `src/App.css:156-162`) are blueprint-style lines with no written purpose. *(R-07)*

## LOW

9. **Generic CTAs and headings.** "Get started" (`src/App.tsx:19`), "Explore Vite" (`src/App.tsx:46`), "Learn more" (`src/App.tsx:52`). "Learn more" also doesn't say where it goes. *(R-15)*
10. **The page content is the template's, not the product's.** The hero image, the counter demo, "Documentation" and "Connect with us" (`src/App.tsx:12-114`) all promote Vite, not this project. *(C-3, R-05)*
11. **No visual identity.** Swap in another product name and the page stays the same. *(R-20)*
12. **The theme follows the OS setting only.** `src/index.css:20, 33` switch on `prefers-color-scheme`, with no toggle and no stated reason for leaving one out. *(R-21)*

## Checked and passing

- No em dashes, statistics, testimonials, FAQ, or navbar links to nowhere (R-02, R-17, R-18, R-24, R-28).
- Body text passes contrast: `#6b6375` on white is 5.73:1, and `#9ca3af` on `#16171d` is 7.04:1. The dark-mode counter button is 5.35:1 (R-25).
- Every control does something: the counter increments, and all links go to real URLs (R-26).
- The counter has a visible `:focus-visible` ring (`#aa3bff` on white is 4.39:1, above 3:1). Links keep the browser's default outline (R-32).
- The page shows no data, so R-27 states don't apply.
