# Skooly ERP Documentation Suite

Welcome to the project documentation for **Skooly**, an all-in-one School ERP web application designed for a single school.

This documentation suite translates the broad 100+ feature scope of traditional multi-school ERP systems into a clean, cohesive, and high-performance product roadmap tailored for school staff, teachers, administrators, and parents.
